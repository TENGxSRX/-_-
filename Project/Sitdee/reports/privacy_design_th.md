# แนวทางความเป็นส่วนตัวสำหรับต้นแบบติดตามท่าทาง

สถานะ: **ข้อเสนอเชิงวิศวกรรมสำหรับ prototype** ไม่ใช่คำแนะนำทางกฎหมาย

## หลักการ

- ระบบไม่ต้องรู้ชื่อหรือใบหน้าของบุคคล เป้าหมายคือวิเคราะห์ landmark ของท่าทางเท่านั้น
- ค่าเริ่มต้นควรประมวลผลภาพบนเครื่องและไม่บันทึกวิดีโอดิบ
- telemetry ใช้ session ID และ anonymous runtime ID เช่น `PERSON_01` เท่านั้น
- แยกข้อมูลสรุป/landmark ออกจากวิดีโอ หากต้องบันทึกวิดีโอเพื่อ debug ให้เปิดใช้เป็นกรณีพิเศษ
- ไม่เก็บข้อมูลเกินความจำเป็น และกำหนดระยะเวลาลบก่อนเริ่มใช้งานจริง

## ระดับข้อมูลที่แนะนำ

| ระดับ | ตัวอย่าง | ค่าเริ่มต้น |
|---|---|---|
| ไม่บันทึก | ภาพจากกล้องและวิดีโอ | แนะนำ |
| บันทึกแบบย่อ | timestamp, pose quality, AI posture, geometry, warning | แนะนำสำหรับ demo |
| บันทึก landmark | จุด x/y/z แบบไม่ระบุตัวบุคคล | เปิดเมื่อจำเป็นต่อการวิจัย |
| บันทึกภาพประกอบ | วิดีโอ/ภาพมีคนอยู่ในฉาก | ปิด ต้องมีเหตุผลและการควบคุมสิทธิ์ |

## การออกแบบ runtime

```text
กล้อง → ประมวลผลบนเครื่อง → anonymous landmarks → ผลสรุป session
                                  └→ ลบ frame ในหน่วยความจำเมื่อใช้เสร็จ
```

ถ้าต้องรองรับหลายคน ให้ใช้ `PERSON_01`, `PERSON_02` ที่มีขอบเขตเฉพาะ session/กล้อง ไม่ผูกกับใบหน้า ชื่อ เครื่องมือ biometric หรือบัญชีบุคคล

## การเก็บรักษาและสิทธิ์

1. ตั้งค่า retention ของ session summary และ telemetry แยกจาก raw video
2. ให้ผู้ดูแลกำหนดโฟลเดอร์จัดเก็บและสิทธิ์อ่าน/เขียน
3. แยกโฟลเดอร์ debug recording และตั้งชื่อ session ที่ไม่ใช้ชื่อจริง
4. ก่อนแชร์ข้อมูลเพื่อการเรียน ให้ลบวิดีโอและ metadata ที่ไม่จำเป็น
5. บันทึกว่า session ใดเป็น `TEST_FIXTURE`, `DEMO` หรือการทดลองจริง
6. แสดงข้อความแจ้งวัตถุประสงค์ให้ผู้ใช้งานทราบก่อนสาธิตหรือเก็บข้อมูลจริง

## ข้อจำกัดที่ต้องสื่อสาร

ผลลัพธ์เป็น prototype เชิงวิศวกรรม ไม่ใช่การวินิจฉัยทางการแพทย์ และค่า `WARNING` เป็นเงื่อนไขของระบบ ไม่ใช่ข้อสรุปสุขภาพของบุคคล
