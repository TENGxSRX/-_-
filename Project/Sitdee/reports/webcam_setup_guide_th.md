# คู่มือจัด webcam สำหรับทดสอบ Live Webcam Prototype V1

## ทำตามง่าย ๆ

1. เสียบ webcam เข้ากับคอมพิวเตอร์
2. ดับเบิลคลิก `check_camera.bat`
3. ดูว่ากล้องหมายเลข `0`, `1` หรือ `2` ขึ้นคำว่า `READY`
4. วางตัวเองให้อยู่ในภาพ แล้วดับเบิลคลิก `run_webcam_demo.bat`
5. หน้าจอ CAMERA SETUP จะรอให้เห็นจุดหลักครบต่อเนื่อง แล้วกด `SPACE`
   เพื่อเก็บค่า neutral calibration
6. นั่งตัวตรงตามธรรมชาติค้างประมาณ 4 วินาที
7. เมื่อ calibration เสร็จ ให้กด `SPACE` เพื่อเริ่มแต่ละขั้นตามที่หน้าจอบอก

ถ้ากล้องไม่ใช่หมายเลข 0 ให้เปิดหน้าต่างคำสั่งที่โฟลเดอร์โปรเจกต์ แล้วใช้
คำสั่งนี้แทน โดยเปลี่ยนเลขท้ายเป็นเลขกล้องที่พบ:

```text
.venv\Scripts\python.exe scripts\run_webcam_demo.py --source 1 --validation --calibration
```

## ตำแหน่งกล้องที่แนะนำ

- วางกล้องห่างประมาณ 1–2 เมตร หรือให้เห็นศีรษะ ไหล่ทั้งสองข้าง และสะโพกทั้งสองข้างเต็มภาพ
- ความสูงประมาณระดับหน้าอกหรือไหล่ และให้กล้องอยู่ด้านหน้า หรือเฉียงเล็กน้อย
- อย่าวางกล้องต่ำมากหรือสูงมากจนลำตัวเอียงในภาพ
- ใช้แสงด้านหน้าให้ใบหน้าและลำตัวสว่าง ไม่ย้อนแสงจากหน้าต่าง
- อย่าให้มีสิ่งของหรือคนอื่นบังลำตัว
- ขาและเท้าไม่จำเป็นสำหรับ V4 รุ่นนี้

## ปุ่มที่ใช้

- `SPACE` เริ่มการทดสอบ หรือไปขั้นถัดไป
- `R` เริ่มขั้นตอนปัจจุบันใหม่
- `Q` หรือ `ESC` ออกจากโปรแกรม

ถ้าระหว่างขั้นทดสอบเห็น `INPUT LOST` ระบบจะหยุดเวลาวัดชั่วคราวจนกว่าจะเห็น
จุดหลักกลับมา ส่วน step 8 ต้องกลับเข้าภาพและรอให้จุดหลักครบก่อนกด `SPACE`

## สิ่งที่ต้องทำใน validation mode

ทำตามข้อความบนจอทีละขั้น:

1. นั่งตัวตรง
2. เอนไปด้านหลัง
3. เอนไปด้านหน้า
4. เอนไปทางซ้าย
5. เอนไปทางขวา
6. กลับมานั่งตัวตรง
7. เดินออกจากภาพ
8. กลับเข้าภาพ
9. ค้างท่าที่ไม่ดีให้นานพอให้ทดสอบคำเตือน

ระบบ AI รุ่น V4 แสดงผลเฉพาะ `UPRIGHT` และ `LEAN BACKWARD` เท่านั้น ส่วน
`FORWARD`, `LEFT`, `RIGHT` เป็น geometry indicators แยกต่างหาก

## ดูอะไรบนจอ

- `POSE: DETECTED` ควรขึ้นเมื่อระบบเห็นท่าทาง
- `AI POSTURE` คือผลจาก V4 สองคลาส
- `GEOMETRY` คือสัญญาณเรขาคณิตทดลอง ไม่ใช่ AI class เพิ่ม
- `NEUTRAL RELATIVE` หมายถึง geometry ถูกเทียบกับท่านั่งตรงของ session นี้
- `INPUT GOOD` / `INPUT LOST` บอกว่าข้อมูลกำลังถูกนับเวลาหรือถูก pause
- `STATE` จะเปลี่ยนตาม temporal engine
- `POSE_LOST` เป็นเรื่องปกติเมื่อเดินออกจากภาพ
- โหมด calibration แสดงค่าเรขาคณิตเพื่อใช้ตัดสินว่าต้องปรับ threshold หรือไม่

ระบบนี้ไม่วินิจฉัยโรคและไม่แสดงคำว่า Office Syndrome ภาพที่เห็นเป็นแบบ
mirror เพื่อใช้งานง่าย แต่ระบบประมวลผลจากภาพต้นฉบับที่ไม่ได้กลับด้าน

โหมด `--calibration` จะแสดงค่า V4 TUP/TLB probability และค่าทางเรขาคณิตเพื่อ
ช่วยวิเคราะห์เท่านั้น ไม่ใช่ผลความแม่นยำของการทดสอบ
