# เช็กลิสต์ข้อมูลห้องสำหรับวางกล้อง

ไม่ต้องวัดละเอียดระดับมิลลิเมตร ใช้ค่าประมาณและวาดตำแหน่งให้เห็นความสัมพันธ์ก็พอ

- ความยาวห้องและความกว้างห้อง
- ความสูงเพดานหรือความสูงจุดติดกล้อง ถ้าทราบ
- ตำแหน่งโต๊ะ/เก้าอี้/เครื่องคอมพิวเตอร์แต่ละจุด
- ทิศที่คนนั่งหันหน้า
- จำนวนที่นั่งหรือโซนที่ต้องการติดตาม
- ตำแหน่งและความสูงของจอคอมพิวเตอร์
- ผนัง ฉากกั้น ตู้ เสา หรือสิ่งกีดขวางใหญ่
- จุดที่ติดกล้องได้จริง เช่น ผนัง มุมห้อง เพดาน
- ทิศที่กล้องหันได้ และความสูงติดตั้งโดยประมาณ
- รุ่นกล้องหรือ horizontal/vertical FOV ถ้าทราบ
- จุดจ่ายไฟและ network ถ้าเกี่ยวกับตำแหน่งติดตั้ง
- โซนที่ไม่ต้องการให้กล้องครอบคลุมเพื่อความเป็นส่วนตัว

ควรใส่ ID ง่าย ๆ เช่น `DESK01`, `DESK02`, `CAM01` และทำเครื่องหมายว่าจุดใดเป็นเป้าหมายหลัก จุดใดเป็น blind spot ที่ยอมรับได้

หลังได้รับข้อมูล จะประเมิน 1 กล้องกว้าง, หลายกล้องแบ่งโซน และกล้องหน้าจุดทำงาน แล้วรายงานข้อดีข้อจำกัดของแต่ละแบบ ไม่ฟันธงจากแผนผังเพียงอย่างเดียว
