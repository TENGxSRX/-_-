# คู่มือเก็บวิดีโอท่านั่ง RGB สำหรับ Local RGB V1

คู่มือนี้จัดทำสำหรับนักเรียน/ทีมเก็บข้อมูล ใช้เพื่อพัฒนาระบบจำแนก “ตำแหน่ง
ลำตัว” เท่านั้น ไม่ใช่การตรวจโรคหรือวินิจฉัย Office Syndrome

## เป้าหมายการเก็บข้อมูล

เป้าหมายแนะนำคือผู้เข้าร่วม 6–10 คน คนละ 2 sessions และคนละ 5 คลิป รวม 60–100
คลิป โดยแต่ละคนต้องทำครบ:

| รหัส | ท่าที่ผู้เข้าร่วมทำ |
|---|---|
| TUP | นั่งตัวตรงตามธรรมชาติ |
| TLF | เอนไปข้างหน้า |
| TLB | เอนไปข้างหลัง |
| TLL | เอนไปทางซ้ายของร่างกายผู้เข้าร่วม |
| TLR | เอนไปทางขวาของร่างกายผู้เข้าร่วม |

## 1. เตรียมกล้องและสถานที่

- ใช้โทรศัพท์หรือกล้อง RGB ที่บันทึกวิดีโอได้
- ถ่ายแนวนอน (landscape)
- ใช้ขาตั้งหรือวางกล้องให้นิ่ง
- วางกล้องห่างประมาณ 1.5–2 เมตร
- ระดับกล้องใกล้ระดับหน้าอก/ลำตัวส่วนบน
- ให้เห็นศีรษะ ไหล่ ลำตัว และสะโพกทั้งสองข้างเท่าที่ทำได้
- ไม่จำเป็นต้องเห็นขาและเท้าครบ
- ใช้แสงด้านหน้า/ด้านข้างที่เพียงพอ
- หลีกเลี่ยงแสงย้อน ห้องมืด ฟิลเตอร์หนัก และ beauty filter
- ทุก 5 ท่าใน session เดียวกันต้องใช้กล้อง ห้อง เก้าอี้ โต๊ะ และ framing เดิม

## 2. คำสั่งสำหรับแต่ละท่า

ให้ผู้เข้าร่วมค้างท่าอย่างเป็นธรรมชาติ ไม่ต้องเกร็งเหมือนทหาร

### TUP — Upright

นั่งหลังและลำตัวตั้งตรงตามธรรมชาติ ลำตัวอยู่ใกล้กึ่งกลาง ไม่เอนไปหน้า หลัง ซ้าย
หรือขวา

### TLF — Lean Forward

เอน “ลำตัว” ไปข้างหน้าอย่างตั้งใจ อาจให้ไหล่และสะโพกเคลื่อนไปด้านหน้าตามธรรมชาติ
ห้ามใช้เพียงการก้มศีรษะ เพราะก้มหน้าไม่เท่ากับ trunk forward lean

### TLB — Lean Backward

เอนลำตัวไปด้านหลังอย่างตั้งใจ อาจพิงพนักเก้าอี้ได้ แต่ต้องให้ลำตัวเป็นส่วนที่เอน

### TLL — Lean Left

เอนลำตัวไปทาง “ซ้ายของผู้เข้าร่วม” ไม่ใช่ซ้ายที่เห็นบนหน้าจอกล้อง

### TLR — Lean Right

เอนลำตัวไปทาง “ขวาของผู้เข้าร่วม” ไม่ใช่ขวาที่เห็นบนหน้าจอกล้อง

ถ้าผู้เข้าร่วมเอนไปหน้าพร้อมซ้าย/ขวาอย่างชัดเจน ให้บันทึกเป็น `ambiguous` ใน notes
และอย่านำคลิปนั้นเข้า training จนกว่าจะตรวจทาน

## 3. วิธีถ่ายแต่ละคลิป

1. กดเริ่มบันทึก
2. ใช้เวลา 2–3 วินาทีแรกจัดท่าและนั่งให้มั่นคง
3. ค้างท่าหลักประมาณ 20 วินาที
4. จบคลิปโดยไม่เปลี่ยนไปเป็นท่าอื่น
5. หยุดการบันทึกก่อนเปลี่ยนท่า

คลิปหนึ่งต้องมีท่าหลักเพียงท่าเดียว ห้ามเดินกล้องหรือเปลี่ยนฉากระหว่าง 5 ท่าใน
session เดียวกัน ระบบจะตัดช่วง settling ตอนต้นได้ภายหลังโดยไม่แก้ไฟล์ต้นฉบับ

## 4. ความแตกต่างระหว่าง sessions

- Session 01 ใช้มุมด้านหน้า/เฉียงด้านหน้าเป็นหลัก
- Session 02 เปลี่ยนระยะเล็กน้อยหรือขยับมุมเล็กน้อยได้
- ห้ามเปลี่ยน setup มากจน session กลายเป็นตัวบอก label
- ทั้ง 5 ท่าใน session เดียวกันต้องใช้ setup เดียวกัน

## 5. การตั้งชื่อไฟล์และโฟลเดอร์

วางไฟล์ตามโครงสร้างนี้:

```text
datasets/raw/local_rgb_v1/
└── participant_01/session_01/TUP/P01_S01_TUP_01.mp4
```

รูปแบบไฟล์ที่อนุญาตเท่านั้น:

```text
P01_S01_TUP_01.mp4
P01_S01_TLF_01.mp4
P01_S01_TLB_01.mp4
P01_S01_TLL_01.mp4
P01_S01_TLR_01.mp4
```

ใช้ `P01`–`P10`, `S01`–`S02` และรหัสท่าตามรายการด้านบน ห้ามใช้ชื่อจริงหรือข้อมูล
ส่วนตัวในชื่อไฟล์

## 6. Metadata และความเป็นส่วนตัว

กรอก `participants.csv` และ `sessions.csv` ด้วย anonymous ID เท่านั้น สามารถระบุ
ช่วงอายุแบบกว้าง ๆ ได้ถ้าจำเป็น ไม่ต้องเก็บชื่อจริง เบอร์โทร อีเมล ที่อยู่ หรือ
หมายเลขเครื่องแบบละเอียด

ก่อนถ่ายต้องอธิบายโครงการและขอความยินยอม ใช้ template ที่
`reports/v5/local_collection_consent_th.md` ห้ามอัปโหลดวิดีโอขึ้นสาธารณะโดยไม่มี
สิทธิ์เพิ่มเติม

## 7. หลังถ่ายเสร็จ

- ตรวจว่ามีครบทั้ง TUP/TLF/TLB/TLL/TLR
- ตรวจชื่อไฟล์และตำแหน่งโฟลเดอร์
- ห้ามตัดต่อหรือเขียนทับ raw video
- รัน `python scripts/local_collection_status.py`
- รัน `python scripts/validate_local_rgb_dataset.py`
- รัน `python scripts/preflight_local_rgb_pose.py`
- เมื่อผ่านการตรวจแล้วจึงรัน `python scripts/extract_local_rgb_features.py`
- ผล MediaPipe ใช้ตรวจคุณภาพ pose เท่านั้น ไม่ใช้เปลี่ยน label ของผู้เข้าร่วม
