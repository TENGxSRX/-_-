# Checklist ก่อนส่งวิดีโอ Local RGB V1

## ก่อนถ่าย

- [ ] Participant ID ถูกต้อง: P01–P10
- [ ] Session ถูกต้อง: S01 หรือ S02
- [ ] ได้รับความยินยอมแล้ว
- [ ] มือถืออยู่แนวนอน
- [ ] กล้องนิ่ง/ใช้ขาตั้ง
- [ ] เห็นศีรษะ
- [ ] เห็นไหล่ซ้ายและขวา
- [ ] เห็นสะโพกซ้ายและขวาเท่าที่ทำได้
- [ ] แสงเพียงพอ ไม่มีแสงย้อนแรง
- [ ] กล้องอยู่ประมาณ 1.5–2 เมตร

## ถ่ายให้ครบ

- [ ] TUP — นั่งตัวตรง
- [ ] TLF — เอนลำตัวไปหน้า
- [ ] TLB — เอนลำตัวไปหลัง
- [ ] TLL — เอนลำตัวไปซ้ายของผู้เข้าร่วม
- [ ] TLR — เอนลำตัวไปขวาของผู้เข้าร่วม

## ตรวจแต่ละคลิป

- [ ] ความยาวประมาณ 20–30 วินาที
- [ ] ช่วงต้น 2–3 วินาทีใช้สำหรับจัดท่า
- [ ] หลังจากนั้นมีท่าหลักเพียงท่าเดียว
- [ ] ไม่เปลี่ยนกล้องระหว่าง 5 ท่าใน session เดียวกัน
- [ ] ชื่อไฟล์ตรงรูปแบบ `P01_S01_TUP_01.mp4`
- [ ] โฟลเดอร์ตรงกับชื่อไฟล์
- [ ] ไม่ใส่ชื่อจริงหรือข้อมูลส่วนตัวในชื่อไฟล์

## หลังถ่าย

- [ ] รัน `python scripts/local_collection_status.py`
- [ ] รัน `python scripts/validate_local_rgb_dataset.py`
- [ ] เก็บ raw video เดิมไว้ ไม่เขียนทับ
