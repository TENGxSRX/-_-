# คู่มือเก็บข้อมูล RGB ในสำนักงานสำหรับ V5

ใช้เมื่อ public data ยังไม่พอ และต้องการเก็บข้อมูลเองอย่างมี traceability
โดยไม่ต้องเปิด webcam ของเครื่องฝึกโมเดลอัตโนมัติ

## เป้าหมายขั้นต่ำ

- ผู้เข้าร่วม 6–10 คนสำหรับ pilot
- คนละ 2 sessions ถ้าทำได้
- ทุกคนทำครบ 5 ท่า: TUP, TLF, TLB, TLL, TLR
- แต่ละท่า 20–30 วินาที
- บันทึกอย่างน้อยมุมกล้องด้านหน้า/เฉียง และมุมด้านข้างเมื่อทำได้

## คำอธิบายท่า

- **TUP:** นั่งตัวตรง ลำตัวตั้ง ไม่เอนไปหน้า/หลัง/ซ้าย/ขวา
- **TLF:** เอนไหล่และลำตัวไปข้างหน้า โดยไม่ใช่แค่ก้มศีรษะ
- **TLB:** เอนไหล่และลำตัวไปข้างหลัง
- **TLL:** ลำตัวเอนไปทางซ้ายอย่างชัดเจน โดยไม่ตั้งใจหมุนตัว
- **TLR:** ลำตัวเอนไปทางขวาอย่างชัดเจน โดยไม่ตั้งใจหมุนตัว

ผู้สาธิตควรค้างท่าให้นิ่ง ไม่ทำท่าผสม เช่น เอนไปหน้าและซ้ายพร้อมกัน
ถ้าท่าผสมเกิดขึ้น ให้บันทึกเป็น `ambiguous` และไม่นำเข้า training

## โครงสร้างการบันทึก

ตั้งชื่อไฟล์ให้เชื่อมกลับได้ เช่น:

`participant_03/session_02/TLF/front.mp4`

เก็บ metadata ต่อวิดีโอ:

| Field | ตัวอย่าง |
|---|---|
| participant_id | P03 |
| session_id | S02 |
| posture | TLF |
| camera_view | front / left_profile / oblique |
| lighting | office_daylight |
| distance | 1.5 m |
| device | phone_model_or_camera_id |
| fps / resolution | 30 / 1920x1080 |
| consent_id | รหัสเอกสารยินยอม ไม่ใช้ชื่อจริง |

## ขั้นตอนต่อ session

1. อธิบายโครงการและขอความยินยอมก่อนบันทึก
2. ตั้งกล้องให้เห็นจมูก ไหล่ และสะโพกทั้งสองข้างเท่าที่ทำได้
3. บันทึก neutral reference สั้น ๆ ก่อนเริ่ม
4. บันทึก TUP, TLF, TLB, TLL, TLR ตามลำดับสุ่มที่จดไว้
5. พักระหว่างท่า และทำซ้ำใน session ที่สองถ้าเป็นไปได้
6. ตรวจไฟล์ว่าภาพไม่มืด เบลอ หรือมีคนอื่นบัง
7. เก็บไฟล์ต้นฉบับแบบ read-only และสร้าง manifest ก่อนประมวลผล

## กติกาคุณภาพและการแบ่งข้อมูล

- ห้ามสร้าง label จากผล MediaPipe หรือจาก classifier
- ห้ามสุ่มแยกเฟรมจากวิดีโอเดียวกันไป train/test
- แบ่งด้วย participant ก่อน ตามด้วย session/video
- ถ้า visibility ของ core landmark ต่ำ ให้คงแถวไว้ใน audit และทำเครื่องหมาย
  quality ต่ำ ไม่ impute เงียบ ๆ
- ใช้ pipeline เดิม: RGB → MediaPipe World Landmarks → hip centering →
  normalized_world / geometry / hybrid
- ไม่เก็บชื่อจริง ใบหน้า หรือข้อมูลสุขภาพเกินความจำเป็น
- ผลลัพธ์เป็นการจำแนกท่าทาง ไม่ใช่การวินิจฉัยโรค

## เกณฑ์ก่อนส่งเข้า V5

ต้องมีครบทั้ง 5 คลาส, แต่ละคลาสมีหลาย participant/session, label ตรงกับวิดีโอ,
ไฟล์มี hash, และมีข้อมูล TUP/TLB ใน source เดียวกันหรือจากหลาย source เพื่อลด
dataset/class confounding ก่อนอนุญาตให้ฝึก V5
